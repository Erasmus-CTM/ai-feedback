# Demo integration gates

ctm-demo is the integration testbox. Use focused checks while wiring one
coherent dependency tuple, then run its already authorized full acceptance
pass once. This policy does not require renewed permission for that final pass.
Repeated broad browser campaigns use the manual browser workflow with AC's
exact confirmation `broad testing campaign`. An invalid confirmation fails the
authorization job before any browser job starts. All runtime, worker, UI and
saved-answer assertions remain unchanged. Native tests remain automatic; other
workflow policies are unchanged.

The composed library retains the reviewed layout and original opaque MathJax
components. Recording their ancestry does not activate the optional CORS
transport or change runtime behavior. Generated downstream copies must come
from the canonical producer at the final immutable library commit.

The live ingmat3a course stays stable. Isolated preparation and testing branches
are permitted; after the coherent demo passes full acceptance and all required
components are merged, ask AC before starting the ingmat migration. AC alone
merges. Check required status settings before removing an automatic browser
status; this patch does not change repository settings or deploy a course.
